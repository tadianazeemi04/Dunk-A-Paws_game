# Dunk-A-Paws: Arcade Basketball 🏀🐾

A physics-based slingshot arcade basketball game built natively for iOS with SwiftUI and SpriteKit.

Aim your trajectory, slingshot your furry athletes across dynamic courts, bounce off backboards, and sink satisfying baskets!

---

## 🌟 Features
- **Intuitive Slingshot Physics**: Drag back, aim using real-time predictive trajectory arcs, and release to shoot.
- **20 Handcrafted Levels**: Featuring moving hoops, obstacle barriers, and bank-shot angles.
- **Cute Character Roster**: Play as charming animal athletes.
- **Clean Swish Mechanics**: Extra points and visual rewards for scoring without touching the rim.
- **Haptic Feedback**: Crisp tactile feedback for shots, bounces, and swishes.
- **100% Offline & Private**: Zero data collection, no account needed, completely playable anywhere.
